# BetterPets releases

This repo has no code in it. Every release here is a new version of BetterPets, with what changed in the
release notes. The plugin checks the latest release to let server owners know when an update is out.

BetterPets is a paid plugin, so the jar is downloaded from wherever you bought it, not from here.
